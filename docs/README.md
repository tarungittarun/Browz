# User guide sources

`Browz-User-Guide.pdf` is generated by `create_user_guide.py` using the screenshots in `images/`. The desktop image is from the Electron app running in a clean Linux CI session; the Android screenshots are from an API 34 emulator running the newer development build. Android screen capture protection was turned off temporarily in the test harness, not in the release app. The desktop toolbar image is a crop of the desktop screenshot. These are not screenshots of the Android public APK, which has an older interface.

To rebuild on Linux with Python 3 and DejaVu fonts installed:

```sh
python3 -m venv .venv-guide
. .venv-guide/bin/activate
pip install reportlab pillow
python docs/create_user_guide.py
```

Review the version-specific claims, links, test status and screenshot dates before regenerating for a later release. The guide's date is fixed to the version it documents.
